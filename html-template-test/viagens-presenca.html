Parte 2: Confirmação de Presença (/api/confirmations/)

Quando uma viagem é criada, registros iniciais (confirm=false) são pré-criados para todos os passageiros aprovados do grupo. O passageiro pode confirmar presença de forma idempotente via POST /api/confirmations/ ou via PATCH /api/confirmations/{id}/confirm/.
